# 六格 single：保护边界与小残留出口

本轮任务入口：`python -m automation.recalculate_strict_single`。

对当前 10240 路线使用的六格 32、40、48 single 重新生成并计算；中间数字上限 48、激进度 0.01。十格路线的步骤、128 开局与三次六格 40 构造 buffer120 的结构保持原有配置。新结果使用独立目录。

## 规则

- `singleEdgeGuard`：与 match 同样，当 F 上方相邻活动块的十进制去个位值与 TARGET 去个位值相等时，禁止 EDGE。这里保守地把 F 的相邻保护块视为 TARGET。
- `singleTidyExit`：目标必须是紧邻 F 上方的普通单格块。除目标之外，活动区域最多占一格，必须是普通块，且值不超过 8；F 两侧残留都计入。禁止多余组合块。
- 真实执行器的提前成功判定、六格 single 与实际等值保护块的连接判定，以及阶段出口检查均采用同一残留要求。

新字段写入模型元数据、生成器检查点及缓存身份。新缓存版本为 `TNPEND03` / `TNQUERY5`。旧缓存仍按其原规则读取，不能用旧缓存满足新规则。

首轮模拟发现旋转操作的终止时机不一致：模型在旋转形成目标时提前结束，真实游戏仍继续投放队列数字。例如活动盘面 `[16,4,F,组合16]` 上移后，模型得到 `[4,F,32]` 并判成功，真实等值连接后还会投放4，留下两个残余4。现已修正严格 single：必须完成旋转和投放全过程后才判断成功。旧首轮三种模型及其概率仅为诊断记录，不作为本轮有效结果。
